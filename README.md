# Cliker · Atelier

Jeu de type cliqueur réalisé avec Godot 4.7. Le joueur développe une chaîne de production composée de points, de pommes, de bois et de pierre.

## Lancer le projet

1. Ouvrir `project.godot` avec Godot 4.7 ou une version compatible.
2. Lancer la scène principale avec `F6` ou le projet avec `F5`.
3. Utiliser `F10` pour afficher les outils de test internes.

## Organisation

- `assets/` : ressources visuelles et sonores du jeu.
- `scenes/` : scènes Godot organisées par fonctionnalité.
- `scripts/` : logique GDScript organisée par système.
- `docs/` : documentation technique et conventions du projet.

La structure détaillée est décrite dans [`docs/PROJECT_STRUCTURE.md`](docs/PROJECT_STRUCTURE.md).
